# 📱 Calculadora Lysifix App

¡Bienvenido a *Calculadora Lysifix App*! Esta es una aplicación móvil de calculadora nativa desarrollada para el sistema operativo Android. El proyecto está enfocado en aplicar buenas prácticas de diseño de interfaz y lógica de programación móvil.

---

## 🚀 Características
* *Operaciones Básicas:* Suma, resta, multiplicación y división implementadas de forma exacta.
* *Interfaz Adaptable:* Diseño limpio y responsivo que se ajusta a pantallas de diversos tamaños de celular.
* *Manejo de Errores:* Control de excepciones común, como evitar la división entre cero.

---

## 🛠️ Tecnologías y Herramientas Utilizadas
* *Lenguaje:* [Kotlin](https://kotlinlang.org) (Nativo)
* *Entorno de Desarrollo:* [Android Studio](https://android.com)
* *Diseño Visual:* XML / Jetpack Compose
